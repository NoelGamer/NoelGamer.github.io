# Noel Studios website

A simple static website for Noel Studios, hosted free with GitHub Pages.

## Put it online (GitHub Pages)

1. Merge this branch into `main`.
2. On GitHub, open the repo → **Settings** → **Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at **https://noelgamer.github.io**.

## Editing

- **Games:** edit the `GAMES` list at the top of `script.js` (name, Roblox link, description, colours).
- **Game pictures:** icons load from Roblox automatically. To use your own, drop a picture into `images/` and set `image: "images/your-file.png"` for that game.
- **Text:** edit `index.html`. **Colours/fonts:** edit `style.css`.
- **Contact button:** change the link in the "Get in touch" section of `index.html`.
